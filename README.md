# herdr-mods

Mods for the [Herdr](https://herdr.dev) desktop app. Each folder is one mod with a `RECIPE.md`.

- [`visible-files`](visible-files): open any file named on the focused terminal.
- [`projects`](projects): jump to a repo's space, or open a new one.
- [`branch-review`](branch-review): review a branch's diff, comment on lines, ranges or files, send the review to any agent, and work through GitHub PR threads.
